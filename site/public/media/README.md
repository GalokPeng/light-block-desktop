# Public demo media

Application screenshots are rendered from real widgets in isolated temporary profiles by `tools/render_showcase.py`. Filenames, notes and recording scenes are fictional. The renderer blocks desktop screen capture and does not read the maintainer's desktop or user profile.

The four JPEGs in `wallpapers/` are exact copies of the maintainer-supplied, AI-generated project wallpapers. Application originals and SHA-256 records are in [`assets/wallpaper-origins.json`](https://github.com/GalokPeng/light-block-desktop/blob/main/assets/wallpaper-origins.json). The smaller WebP previews are website derivatives. These project assets follow the project MIT license.

Online-gallery screenshots include reduced, cropped previews of third-party photographs. Their authors, source pages and individual licenses are listed in the [wallpaper credits](https://github.com/GalokPeng/light-block-desktop/blob/main/docs/wallpaper-sources.md). Individual media retain their original licenses. The composite online-gallery screenshot is offered under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) to accommodate share-alike content; the application source remains MIT. The gallery screenshot displays the first nine image entries in the credits, including Aaron Burden's CC0 Winter Ice Crystal image as the selected preview.

The taskbar SVGs are project-drawn layout diagrams, with generic application symbols and a fictional clock; they are labeled as diagrams on the website. They are not screenshots of a personal taskbar.

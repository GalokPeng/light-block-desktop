# Online wallpaper previews

Every preview uses the license of its own source work. The [catalog](../catalog.json) identifies each work by filename stem and provides its title, author, source page, license, license URL, original download URL and SHA-1. These media files have individual licenses independent of the website code.

The WebP files are resized covers. The MP4 files are resized, muted excerpts of up to five seconds from the original GIF or video. Credits and license links are also visible when the work is selected in the gallery.

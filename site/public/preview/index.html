安装前请了解

  • 安装目录、设置与缓存独立，不读取或迁移正式版个人数据。
  • 不会通过正式版更新按钮推送，不替换 Python 1.0.0；main 分支保持正式版。
  • 测试桌面收纳、任务栏或鼠标美化前，请先退出另一个版本，避免两个程序同时接管桌面。
  • 可单独卸载测试版。卸载前先退出测试程序，让其恢复原生桌面设置。

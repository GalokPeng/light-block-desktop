桌面与截屏

从桌面到工作流

壁纸、收纳和截屏可按需使用。每个工具都能独立开启。

01 / 壁纸

静态、GIF 和视频壁纸

导入本地素材，按屏幕选择铺放方式。GIF 与视频直接读取源文件，静态壁纸交由 Windows 显示。

  • 登录后可静默启动并恢复壁纸。
  • 支持在全屏、锁屏、熄屏或电池供电时暂停。

02 / 收纳

给文件与便签留个位置

将文件夹、快捷方式、系统入口和文件按类型整理到桌面。点击半透明收纳组展开，点击空白处收回。

  • 分组可改名、调整图标尺寸和透明度，文件仍在原位置。
  • 关闭收纳会恢复原有图标可见性。便签可单独贴在桌面。

03 / 截屏

捕获、标注、贴图与录制

用 Ctrl + Alt + A 打开选区工具。选择窗口或区域后，工具栏提供文字、箭头、画笔、马赛克和序号。

  • 贴图置顶，双击关闭并复制。
  • 可滚动拼接长图，或录制选区后保存为 MP4、GIF 或无损 MKV。

开始使用

安装到 Windows

从 GitHub Releases 下载 Setup 安装包，或解压免安装 ZIP 后运行。安装与程序界面读取 Windows 显示语言。

下载 Windows 版 ↓
如何升级？

退出旧版后运行新版 Setup。它会沿用已有配置。免安装版请先完整解压，再打开程序。

录屏需要额外组件吗？

录屏和媒体导出需要单独安装 FFmpeg 命令行工具并将其加入 PATH。壁纸播放、静态截屏与收纳可直接使用。

设置和素材存在哪里？

配置目录为 %LOCALAPPDATA%\StillWallpaper。你的壁纸、桌面文件和剪贴板历史由本地程序处理。

中英文如何切换？

程序在启动时读取 Windows 显示语言。中文系统显示简体中文界面，其他系统默认英文。安装器额外提供繁体中文。

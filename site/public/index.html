功能预览

用自己的方式布置桌面

壁纸截屏与录屏收纳与任务栏桌面便签

01 / 壁纸

静态、GIF 和视频壁纸

导入本地图片、GIF 或视频，壁纸库会保存原画质副本。选择屏幕与铺放方式后即可应用，视频封面从实际画面生成。

  • 视频壁纸默认静音，可在「播放与性能」或桌面右键菜单中切换声音。
  • 登录后可恢复壁纸。动态壁纸支持在全屏、锁屏、熄屏或电池供电时暂停。
  • 在线精选提供 20 张静图、10 款 GIF 与 20 段视频，支持搜索、预览与原文件下载。每项均附作者和许可。

02 / 截屏与录屏

截下来标注，录下来再剪

默认按 Ctrl + Alt + A 选取窗口或区域。截图可以标注、滚动拼成长图、复制为 PNG 或在原位贴图。

  • 录屏结束后贴屏预览，拖动双端时间指针裁剪，方向键逐帧微调。
  • 按选定画质和帧率导出 MP4、GIF 或无损 MKV，GIF 支持快速与精细调色。

03 / 收纳与任务栏

收好桌面，美化原生任务栏

桌面收纳可放在屏幕上方、中间或下方。按名称、修改时间或分组排列，搜索并打开桌面项目。关闭收纳时恢复原有图标显示状态。

  • 可选任务栏美化。在 Windows 11 22H2 或更新版本的 x64 主屏上，电源与搜索、应用、系统托盘分三段居中，保留系统搜索与托盘菜单。
  • 全屏或窗口遮住底栏时可自动隐藏，鼠标移到屏幕底边即可唤出。
  • 电源旁提供任务栏设置和任务管理器快捷按钮。新增桌面文件先显示为图标，右键即可放入收纳或指定分组。

04 / 桌面便签

把待办贴到桌面

右键桌面空白处选择「轻块桌面 · 新建便签」，即可直接贴出一张便签。Windows 11 先打开「显示更多选项」。拖动可调整位置，双击即可编辑。

  • 在「便签与任务」中搜索内容、设到期提醒、标记完成或归档。
  • 内容自动保存在本机，已贴出的便签可在关闭设置窗口后继续显示。

开始使用

安装到 Windows

下载并运行最新版 Setup。安装与程序界面读取 Windows 显示语言。免安装 ZIP 可在 发布页 获取。

下载 Windows 安装包 ↓
如何升级？

在软件左下角点击「立即更新」，可查看下载进度。校验安装包后自动退出并启动安装，沿用已有配置；也可手动下载 Setup。

安装后如何录屏？

从 v0.7.4 起，安装包和免安装版自带录屏组件。按 Ctrl+Alt+A 选择区域，再点击工具栏上的录屏按钮。结束后可预览并导出 MP4、GIF 或无损 MKV。

设置和素材存在哪里？

默认保存在安装目录的 data 文件夹。首次启动时复制旧配置。安装目录不可写时，沿用 %LOCALAPPDATA%\StillWallpaper。

中英文如何切换？

程序默认跟随 Windows 显示语言。设置右上角可切换简体中文或英文，安装器也提供繁体中文。

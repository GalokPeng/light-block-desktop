Before installing

  • Separate installation, settings and caches. Stable personal data is not imported or migrated.
  • Not delivered through stable updates. It does not replace Python 1.0.0; main stays on the stable version.
  • Exit the other version before testing the organizer, taskbar or pointer effects so only one app controls the desktop.
  • Uninstall the preview separately. Exit it first so it can restore native desktop settings.

Report an issue

Include your Windows version, display scale, reproduction steps and screenshots with personal information removed.

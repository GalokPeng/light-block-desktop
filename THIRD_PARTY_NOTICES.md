The native taskbar DLL and cursor host contain the linked compiler runtime. The corresponding notices are in `licenses/Native-*.txt`. Windhawk's runtime is separate from the build toolchain and is not included in the distribution. The three cursor themes are original geometric artwork generated by `tools/generate_cursors.py` and are covered by this project's MIT license.

The replaceable Qt and Shiboken libraries are under `_internal` and its subdirectories. Installation into the default per-user directory gives the user access to those files. Recipients may replace them with compatible modified versions and reverse engineer the application as needed to debug those modifications under the LGPL. The application source, dependency versions and build instructions accompany the release. License texts are in `licenses/` and in the runtime license files.

See [Qt attributions](https://doc.qt.io/qt-6.11/licenses-used-in-qt.html), [Qt Multimedia attributions](https://doc.qt.io/qt-6.11/qtmultimedia-index.html#licenses-and-attributions) and [Qt for Python licensing](https://doc.qt.io/qtforpython-6/licenses.html).

Screen recording and export launch the bundled, standalone FFmpeg CLI as a separate process. The executable is built from [FFmpeg 8.1.3](https://www.ffmpeg.org/releases/ffmpeg-8.1.3.tar.xz), [x264](https://code.videolan.org/videolan/x264/-/commit/b35605ace3ddf7c1a5d67a2eb553f034aef41d55) and [zlib 1.3.2](https://github.com/madler/zlib/releases/tag/v1.3.2). It is distributed under [GPL-3.0-or-later](licenses/FFmpeg-CLI-GPL-3.0.txt). See the [zlib notice](licenses/FFmpeg-CLI-zlib.txt) and [GCC Runtime Library Exception](licenses/FFmpeg-CLI-GCC-exception.txt) for the linked components. The MinGW-w64 runtime notices are in `licenses/Native-MinGW-w64-runtime.txt`. Qt's shared multimedia libraries and the MIT application are separate works.

The matching [release page](https://github.com/GalokPeng/light-block-desktop/releases) offers `Qingkuai-v<VERSION>-ffmpeg-source.zip`, which contains the corresponding sources and build scripts. The scripts pin the compiler and assembler packages, including [w64devkit 2.6.0](https://github.com/skeeto/w64devkit/releases/tag/v2.6.0), whose release provides the toolchain source archive. The optional local build argument `-FFmpegPath` accepts a compatible `ffmpeg.exe`. Distributors using it must provide licensing and corresponding source for the chosen executable.

The installer is built with [Inno Setup](https://jrsoftware.org/isinfo.php). Its bundled Simplified Chinese and Traditional Chinese message files come from [upstream commit 31ee6e3](https://github.com/jrsoftware/issrc/tree/31ee6e35383c530cca8f047216045d3f61ca8be1/Files/Languages). The translation headers and [Inno Setup License](licenses/Inno-Setup.txt) are retained.

Their original bytes, source basenames and SHA-256 records are in `assets/wallpaper-origins.json`. Existing original motion demos are unchanged. Website previews are separate resized derivatives.

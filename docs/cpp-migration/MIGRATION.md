## 独立测试分支补记（2026-11-13）

当前测试分支为 **1.1.0-beta.1 · 测试版（极度优化）**，不替换正式 Python 1.0.0、不自动迁移正式用户数据。以下历史账本中的 `0.1.0-local`、刷新及文件图标差异仅指早期构建；当前变化与证据见 [UI 对齐审计的补记](UI_PARITY_AUDIT.md#preview-branch-follow-up-2026-11-13)。

- 美化折叠区使用左标题、右开关；图标尺寸改为小／中／大横向滑块，收纳框按 DPI 与尺寸重新布局，悬停留出放大空间。显示器使用友好名称、分辨率、缩放比例，只列一次主屏。
- 主题／语言按钮尺寸、中文字体覆盖、逐页标题与关于页布局已调整；媒体工作台保留内嵌页面和原版导出参数，从截屏页进入，工具页不再重复入口。设置继续即时生效，统一左文字、右控件和至少64逻辑像素行高；屏幕与填充方式仅保留在壁纸页。
- 文件工作台接入后台 Shell 图标，按可见项加载，原生待办上限48、两侧缓存各128；复制像素所有权，取消过期扫描时校验条目身份。关闭页不等待 Shell 调用。精确元数据读取、GDI 同步及像素所有权已通过本轮联编夹具。
- 在线刷新已补远端清单校验与失败保留；仍不绕过本机网络拦截，实际素材下载/播放另行验收。
- 本地和在线图库固定三列；本地恢复类型／图像尺寸／MB／扩展名，缺文件禁用应用。静图元信息和解码最多1项运行＋1项最后请求；取消与过期结果不写回界面。本地Qt缩略图缓存24项。应用壁纸先停预览，同一GIF需要点击播放才再次预览，避免重复解码。
- GIF／视频装饰使用原生透明兄弟层保留标题、类型与渐变，实际隐藏HWND夹具通过，不代表公开桌面视频合成已验收。
- 针对宽预览框的视频偏左，原生MF内嵌播放子窗口改为按原比例居中，渲染目标使用整个子窗口；GIF仍使用完整宿主和居中绘图，Qt备用通道保持原比例。动态图封面同步使用contain。三个Qt比例下，MF／Qt视频／GIF共9个真实子进程的宽→高→宽几何、解码和退出通过；隐藏GIF使用专用probe，未把结果当作可见合成或真实跨屏验收。详细路径与限制见审计中的居中修复补记。
- 最终联编 `LightBlockUi-ec6866f1027f.dll` 在100／150／200%实际比例的综合UI夹具均通过，含修复后的原生截屏工具栏归属、ABI3录屏音频预备控件与裁剪循环；证据在 `.local/appearance-abi3-final-dpi*/screens`。音频UI测试使用假回调，没有录取真实声音；后台与安装验收另行记录。
- 100%、150%、200%实际 Qt 比例下的中英×明暗界面断言通过；修复图标缓冲所有权后200%复测通过，含 Win键、小键盘和标点快捷键往返。目录、DLL及EXE摘要见审计补记。该阶段截图未显示真实桌面，不代替最终安装包、Explorer接管、多屏热插拔、IME、长时运行验收，也不声称已逐像素复现。

## 本轮修复原则

- 设置在当前配置上提交单字段，保留无关异步变化，失败回滚。取消的是设置页全局保存应用；文件保存、改名确认和工作区保存仍各自明确执行。
- 预览嵌入原页面，桌面播放与预览通道独立。隐藏本地列表变更不停止在线预览；选择/类别/隐藏变化清理旧预览意图，晚到结果不重新播放。
- 在线封面最多3项并发、32张解码缓存，隐藏时释放；动态预览使用校验后的完整媒体。原文件下载不降低画质。
- 剪贴板、文件、专注及启动器采用Qt界面连接原生服务；既检查首次主题，也检查已创建页面切换及隐藏后恢复。
- 文字样式更新保留输入控件/光标，滚轮切换标注目标前先提交文字，防止样式串写；各工具组保留参数。便签桌面与管理页共享正文。
- 动画模型与原版432帧数值对照、限制绘制区域、空闲停绘；不把模型检查说成逐帧视觉一致。

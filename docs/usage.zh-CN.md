# 轻块桌面测试版使用指南

[English](usage.en.md) · [测试分支首页](../README.md)

> **测试版（极度优化）· 尚不稳定。** 本指南描述独立的 `1.1.0-beta.1` 测试分支，不替代正式 Python 1.0.0；正式 `main`、官网及自动更新渠道保持原状。

轻块桌面面向 Windows 10 / 11 x64，提供壁纸、截屏录屏、桌面收纳、原生任务栏美化和本地工具。设置、便签和下载的壁纸保存在本机；在线图库和更新按需联网。

## 安装与日常操作

从 [GitHub Releases](https://github.com/GalokPeng/light-block-desktop/releases) 选择标记为 Pre-release 的测试包，或完整解压其便携 ZIP 后运行 `轻块桌面测试版.exe`。请保留同包 DLL、插件、assets 和运行时目录，不要只复制 EXE。用户无需另装 Python、Qt 或 FFmpeg。

安装向导跟随 Windows 显示语言，支持简体中文、繁体中文和英文。程序首次使用时，中文系统默认简体中文，其他语言默认英文；右上角语言按钮切换中英文，太阳／月亮按钮切换明暗主题。版本号在「关于」中显示。

设置在修改后自动保存和生效，滑块有短暂合并更新。关闭设置窗口后，已启用的桌面服务和托盘继续运行；要彻底退出，请使用托盘的退出命令。登录自启动在「设置」中开启。

左下角「测试版说明」打开测试说明，不检查或安装正式版更新。本分支只提供独立预发布安装包，不推送给正式版用户。

## 升级与数据目录

测试版使用独立安装标识、程序名和自启动键。默认数据目录为测试程序旁的 `data-preview`；不可写时使用 `%LOCALAPPDATA%\LightBlockDesktopPreview`。「关于 → 打开配置与日志文件夹」显示活动目录。

启动不读取、不迁移、不删除正式版配置，也不会关闭正式版进程。即使显式用 `--data-dir` 指定一个含 Python `settings.json` 的目录，也会拒绝使用，要求换独立目录。不要把测试版手工复制到正式安装位置。

测试版自身以后更新时保留自己的数据。尚在源码中的旧数据迁移模块仅用于隔离夹具与后续兼容性研究，不是本次测试版的用户升级入口；旧便签、剪贴板和撤销日志不会自动出现在测试版中。正式版及其 `organizer_files` 等文件请保留，不要交给测试版清理。

桌面收纳、任务栏和系统指针属于全局资源。测试前先关闭其他版本对应的美化功能，避免同时接管；启动测试设置窗口本身不应接管这些资源。开发者始终使用全新 `--data-dir <目录>` 进行验证。


## 壁纸

导入本地静图、GIF 或视频，会在当前数据目录的 `media` 中保存原画质副本。选择壁纸后在页面内预览；视频点击播放，预览不另外弹窗。选择显示方式和显示器，再点击「应用到桌面」。预览和桌面播放使用独立通道，离开预览不应停止桌面壁纸。应用壁纸时先停止当前预览，避免重复解码；需要时点击「播放预览」重新查看。

静态壁纸通过 Windows 壁纸接口应用，准备图片与系统调用不阻塞设置窗口。GIF 和视频在受监督的子进程中播放；切换请求会清理旧播放实例。格式能否硬件解码仍取决于本机驱动和系统组件，不保证所有格式均使用硬解。

视频声音默认关闭。「设置 → 播放与系统」可调整壁纸声音，也可用「声音开关」或安装版的桌面右键声音入口，开启前需要确认。已确认的偏好会保存；它只影响桌面播放，不改变独立预览通道。全屏暂停、电池暂停和启动后恢复壁纸默认开启。停止壁纸、播放／暂停和恢复原 Windows 壁纸在右侧操作区。

右键导入项可删除库内副本，导入前的原文件保留。正在使用或读取的文件需要先停止相关使用再删除；失败会显示提示。内置素材右键操作只隐藏目录项，不删除随包资源。

### 在线壁纸

「在线壁纸」提供静态、GIF、视频三个入口。随包精选为静态 20 张、GIF 10 款、视频 20 段；来源原文件至少 1920 × 1080、单项不超过 20 MB。可搜索双语名称和目录标签，查看作者、许可、来源与公开热度依据。版权和使用条件以单个素材的来源许可为准。

选择卡片后点击「开始预览」，在页内观看；停止预览返回列表。封面按需读取，有并发与缓存上限。动态预览先取得并核验素材，下载完成后才开始播放；这一步可能受来源网络影响。正式下载保留原文件字节，显示进度及已下载状态，可再导入或应用到桌面。预览缓存经再次核验后可复用。

**刷新会获取官方公开 URL 目录，并重新加载封面。** 目录大小限制为 2 MB，并校验格式、来源、文件大小、分辨率及摘要字段；刷新失败保留旧目录，下载进行中不会替换目录。离线可使用已下载原文件；未缓存内容需要能访问素材来源。本地网络策略可能拦截部分来源，界面会报告失败，程序不绕过本地拦截。授权与筛选依据见[素材来源](wallpaper-sources.md)和[评估记录](wallpaper-evaluation.md)。

## 美化

桌面收纳、原生任务栏、鼠标与指针分为独立折叠区，可以分别开启。

- **桌面收纳**：默认居下，也可居上或居中；按名称、修改时间或分组排列。支持搜索、分组命名与配色、图标底板和整体背景配色、不透明度和图标尺寸。新增桌面内容先显示，默认一分钟后自动收纳，可关闭或右键指定分组。关闭收纳恢复原图标显示状态。
- **任务栏**：在支持的 Windows 11 任务栏上，将快捷按钮／原生搜索、应用、系统托盘分为相邻的三段，保留系统搜索与托盘操作。可调整圆角、背景颜色和不透明度；前台窗口占用任务栏区域时隐藏，触底唤出。Explorer 布局与第三方工具可能影响兼容性，不支持的环境不会强行接管。
- **鼠标与指针**：系统默认、流线、棱镜、像素；指针尺寸与颜色独立调整。点点、飘落、光芒可分别选择并自定颜色，关闭时停止效果，退出恢复系统指针。

系统夜间模式入口位于「设置」；按钮打开 Windows 相应设置，不假装接管系统色温调节。系统不支持时不可用。

工具快捷键可在「设置 → 工具偏好」单独启用，测试版默认关闭：`Ctrl+Alt+Space` 打开启动器、`Ctrl+Alt+V` 打开剪贴板、`Ctrl+Alt+R` 开始／结束录屏。截屏快捷键单独设置；录屏进行中仍保留停止快捷键。与系统或其他应用冲突时，注册失败会提示并保留原有设置。

## 截屏与录屏

默认 `Ctrl+Alt+A` 开始截屏，快捷键可在截屏设置中更改。选择区域后，拖动边缘改变选区；右键取消当前选区并重新框选，未选区时退出。

工具栏按当前工具显示参数：矩形／圆形、填充、虚实线、粗细、圆角、箭头、直线、画笔、高亮、文字、序号和马赛克。选项框只可选择。文字直接在画布内输入，可拖动、双击继续编辑；字体、大小、颜色在子栏调整。滚轮调整当前标注参数，不用于改变截取框大小。

完成后可复制、保存或原位置贴图。贴图可 `Ctrl+滚轮` 缩放，右键开启同一套编辑工具，双击关闭。长截图按选区滚动采样并匹配重叠，旁边显示累计缩略图。切换页面后点击“采集下一屏”：有重叠时自动匹配，没有重叠时整页追加，并可撤销。点击“完成”直接生成贴图，没有滚动也可以完成；未匹配的普通滚动帧不会强行追加，可先用“采集下一屏”明确采集该页。长图贴图普通滚轮上下浏览，`Ctrl+滚轮` 缩放，`Shift+滚轮` 调整透明度，复制和保存仍保留整张原图。

框选后点击录制，录制期间保留区域边界；停止按钮或本次录制的 `Ctrl+Alt+R` 结束。结束后先贴屏预览，再裁剪、标注或导出。时间轴两端可拖动；`Tab`／`Shift+Tab` 切换左右端点与播放头，方向键移动一帧，`Shift+方向键` 移动十帧。

导出可选择 MP4、GIF 或无损 MKV，以及原尺寸／1080p／720p／480p、原帧率或固定帧率。GIF 提供快速与精确调色，快速模式缩减的是调色板分析采样，不擅自修改所选输出尺寸。录制前的准备栏可分别启用系统声音、麦克风，或同时录制，两项默认关闭；点击“开始”后才启动设备。停止后在后台整理音轨，再进入预览。设备被拔出、默认设备改变或权限不足会显示原因，不能静默当作带声录制成功。GIF 不含音频；媒体工作台打开已有视频后，适用的导出格式可保留其音轨。

**录制和导出使用完整发行包中的 FFmpeg 运行时，并校验固定摘要，不从系统 PATH 寻找替代程序。** 若组件缺失或校验失败，重新安装／完整解压对应测试包；开发者重新构建暂存运行时。不要按旧版提示另装任意 FFmpeg 或复制未知 EXE。

准备栏的声音选择会保存为下次录制的默认值，未点击开始不会采集。录屏预览中的「试听／静音」只控制预览播放，不会删除导出的音轨。系统声音和麦克风使用 Windows 内置 WASAPI 采集，无需安装虚拟声卡。停止后的音轨合并直接复制视频流，不额外重压画面；原尺寸、较高帧率和无损录制仍会增加 CPU、磁盘和内存开销，不保证所有机器都能硬件编码。

如果音频驱动无响应，任务会超时结束并保留已录文件。若设备仍被占用，可正常退出测试版以释放；未完成的音频缓存仅在原进程结束后的下次启动清理。合成测试覆盖双音轨和超时生命周期，实际声音设备、隐私权限与音画启动延迟仍需在目标电脑确认。

## 工具

- **便签**：在工具页或安装版桌面右键中新建。Windows 11 可能需先点「显示更多选项」。便签贴在桌面层，可拖动标题、拖动边缘或角落调整大小；正文过长可滚轮浏览，滚动条隐藏。支持颜色、全文搜索、完成状态、归档和提醒。
- **剪贴板历史**：自动记录默认关闭，启用后保存在本机；也可明确点击「记录当前内容」。列表可搜索、固定、复制和删除，选中后在页内预览文字或图片。测试夹具使用合成数据，不读取真实剪贴板。
- **快速启动**：检索桌面和开始菜单项目，并支持受限的简单算式；只有选择执行时才打开对应项目。
- **文件工作台**：页内浏览、预览、摘要和批量改名。修改前查看计划；新版产生的撤销／恢复记录属于新版格式，不执行旧版操作日志。
- **专注工作区**：专注／休息计时、历史与工作区切换；测试版历史独立保存，不自动导入正式版历史或计时。

## 排查与开发

「关于」可以打开数据目录。当前运行日志为 `native.log`，测试数据与正式配置分开；分享日志前检查其中的文件路径。无法读取的旧壁纸或被网络阻止的媒体需分别处理，不能据此认定全部配置丢失。

没有通用于所有电脑的内存占用数值：视频分辨率、帧率、解码后端和显示器数量都会影响使用量。旧版 Python 的测量结果不代表当前版本；性能需在具体机器与场景下测量。

本测试分支运行时为 C++23、Qt Widgets 与 Win32，Python 只用于开发构建工具。开发时使用隔离目录：

```powershell
./build.ps1
& ".\dist\LightBlockDesktopPreview\轻块桌面测试版.exe" --data-dir "$PWD\.local\dev-profile"
./tools/test.ps1 -SkipBuild
```

完整旧实现保留在 [`python-v1.0.0`](https://github.com/GalokPeng/light-block-desktop/tree/python-v1.0.0) 和 [`v1.0.0`](https://github.com/GalokPeng/light-block-desktop/tree/v1.0.0)。贡献、构建与发布见[贡献指南](../CONTRIBUTING.md)和[发布流程](release.md)。应用源码采用 MIT；随包组件和壁纸仍遵循各自的[第三方许可](../THIRD_PARTY_NOTICES.md)。

# 轻块桌面使用指南

[English](usage.en.md) · [项目首页](../README.md)

本地运行的 Windows 桌面工作台，Python 3.11 + PySide6。包含静态 / GIF / 视频壁纸、可选玻璃桌面收纳、截图录屏，以及五个独立效率工具。无账户、广告、遥测或云端上传。

## 直接使用

Setup 跟随 Windows 显示语言，支持简体中文、繁体中文和英文。程序启动时读取相同设置，中文系统显示简体中文，其他语言使用英文。

下载 Releases 的 `Setup-x64.exe` 安装，或完整解压 `Windows-x64.zip` 后运行 `轻块桌面.exe`。便携版保留同目录的 `_internal` 文件夹。

升级前退出旧版，再启动新版。新版默认把设置和壁纸库放在安装目录的 `data` 下，并复制 `%LOCALAPPDATA%\StillWallpaper` 中的旧配置。安装目录不可写时沿用原目录。「关于」页可以打开当前数据目录。已开启自启动的用户可在新版重新打开自启动开关以更新路径。截图快捷键 Ctrl+Alt+A 默认开启，收纳和剪贴板历史仍可分别开启。

明暗主题会同步到 Windows 窗框。旁边的语言按钮可选跟随系统、简体中文或英文。设置与托盘立即切换，其他已打开的工具会在下次打开时使用新语言。左下角有新版时点击「立即更新」，按钮显示下载进度，再点一次可取消下载。完整安装包通过官方 SHA-256 校验后，软件会正常退出并启动安装。安装版沿用原安装目录，完成后重新打开并保留配置；便携版或源码运行会打开安装向导。

更新下载跟随界面语言选择初始来源。英文优先 GitHub，中文优先 `gh-proxy.com`，另有 `ghfast.top` 及官方来源回退。失败、停滞或初始持续低速时会换源，不执行未通过校验的安装包。关闭设置窗口不会中断正在进行的下载。

运行程序后，右键桌面空白处即可使用带轻块桌面图标的「新建便签」和「切换轻块桌面声音」。Windows 11 的新式右键菜单需先点「显示更多选项」。在收纳面板内右键也可使用这两个操作。便签新建后直接贴在桌面，可双击编辑。

视频壁纸每次启动默认静音，可在「设置 → 壁纸与性能」开启「轻块桌面声音」。开启前会提示确认；切换声音会重新加载当前视频。全屏时暂停、电池供电时暂停和启动后恢复壁纸默认勾选。

在壁纸库中右键自己导入的壁纸，选择「删除壁纸」，或使用右侧的同名按钮。删除的是壁纸库中的副本，导入时的原文件保留。删除正在应用的壁纸时先恢复原来的 Windows 壁纸。内置示例壁纸不可删除。

静态壁纸切换时按钮显示「正在切换壁纸…」，完成后才提示已应用。准备图片与 Windows 设置在独立任务中处理，界面可继续操作；超时或失败后可重试。关闭设置窗口不会中断正在进行的切换，退出软件会结束切换任务。

### 在线壁纸

壁纸页选择「在线壁纸」，提供静态 20 张、GIF 10 款、视频 20 段，默认静态，取消内容分类。可在当前媒体类型中搜索中英文名称、原始文件名或标签。所有入选来源文件至少 1920 × 1080，单项不超过 20 MB；10 款 GIF 按维护者确认与本地复看版一致；要求原始 1080p、16:9、20 MB 内与明确授权，不以点赞／收藏作为门槛。选择卡片后显示作者、许可及核对时的公开支持票或浏览、收藏数据；「热度依据」可打开原始统计页面。GIF 浏览量只合计来源已公开的日期，提示中显示区间与可用天数，未公开的数据不推算。点击「开始预览」在页内查看大图或动态画面，「停止预览」返回列表。视频默认静音，下载保持发布者文件的原始字节。GIF 与精选中的 WMV、WebM、OGV 均直接播放，无需额外安装组件。

点击「下载原文件」显示进度，下载期间可取消，校验通过后可直接「应用到桌面」。原文件保存在当前数据目录，不重新压缩。关闭设置后正式下载继续，退出软件会取消。删除本地下载后，在线卡片恢复可下载状态。目录暂不可达时显示已有精选；素材能否预览和下载仍取决于来源网络。[来源与授权](wallpaper-sources.md)

## 桌面收纳

收纳面板默认居中。右键选择「移动位置」后拖动面板，松手后会保存位置并退出移动状态。右键「恢复居中」可回到默认位置。把小收纳框拖到另一个收纳框上可调整顺序。

进入「桌面收纳」并打开开关。收纳主页和分组网格隐藏滚动条，仍可用滚轮浏览。桌面显示手机式文件夹总览，Windows 原生图标同时隐藏。项目按文件夹、快捷方式、系统图标和文件后缀归类。「同步分类」可补充新项目。

单击文件夹放大为应用网格。单击空白处、点到面板外，或成功打开项目后，网格收回到文件夹总览。开启和收回时，桌面窗口尺寸保持固定，图标和文字在过渡期间保持可见。分组只读取当前视口内的图标，滚动到新项目时继续读取。动效跟随 Windows 的动画效果设置。鼠标进入时面板和文字一起变清晰，离开时一起淡化。可设置分组名称、颜色、图标尺寸及面板透明度。

点击桌面收纳面板上的标题可直接编辑。展开分组后，点击分组名也可编辑。回车或点击别处保存，Esc 取消。名称可以留空，原位置仍可再次点击。右键面板可选择「添加新分组」或使用其他管理操作。

拖入应用、文件和文件夹可添加入口。项目可重命名显示名称、排序或移至其他分组。

关闭收纳或正常退出应用会恢复 Windows 桌面图标的原显示状态和布局。此前版本移动到托管目录的文件会尝试还原到原桌面目录，Windows 为这些返回的文件安排图标位置。

收纳开启后，桌面新建或粘贴的文件先显示为独立桌面图标，可拖动位置，并提示「右键可以放入收纳哦」。默认开启「自动收纳新增内容」：显示 1 分钟后自动放入收纳，正在拖动、悬停或操作菜单时暂缓。可在「桌面收纳 → 桌面收纳设置」关闭，改为右键手动「放入收纳」；分组排列下还可选择目标分组。原文件始终保留在桌面。重启或重新开启自动收纳后，尚未收纳的项目重新计时 1 分钟。通过文件系统通知发现新增内容，收纳计时使用单次截止定时器，不增加周期性桌面扫描。

桌面收纳页按「桌面收纳设置」「任务栏设置」「分组管理」折叠展示。分组颜色同时用于小分组卡片和展开后的面板。支持原生三段布局的 Windows 11 可在任务栏设置中选择背景颜色、拖动 0–100% 背景不透明度；0% 移除自定义背景，应用图标、文字与托盘保持完整。Windows 10 或不兼容布局保留系统配色，并禁用对应控件。关闭美化恢复原生外观。

原生任务栏美化的左侧按「电源 → 任务栏设置 → 任务管理器 → 原生搜索」排列。齿轮按钮直接打开 Windows 任务栏设置，柱状图按钮打开系统任务管理器。三个图标按钮采用固定紧凑尺寸，悬停显示说明，不再预留大块空白，也不改变中间应用图标的间距。

## 截屏

| 工具 | 功能 |
| --- | --- |
| 选区 | 默认 Ctrl+Alt+A 打开统一截屏工具。可在「截屏」页按下一组键并点击「应用」。支持智能窗口、手动区域和当前屏幕。Alt 选整个窗口，蓝框手柄调整尺寸，右侧移动图标用于拖动选区。右键清空当前选区并重选，无选区时右键退出 |
| 标注编辑 | 点击工具图标会在下方显示对应选项。矩形和圆形支持填充、虚实线和粗细，矩形可调圆角。按住 Shift 可画正方形或正圆。马赛克可按圆角框选，也可用画笔涂抹。文字可在选区内直接输入、拖动和双击编辑。滚轮可调整光标所指的文字、箭头、序号等标注 |
| 贴图 | 在选区工具栏点「贴图」直接置顶。按住 Ctrl 滚动滚轮缩放。右键选择「编辑贴图」即可在原窗口标注，点「完成编辑」收起工具栏。退出编辑后，双击贴图可关闭并复制 |
| 长截图 | 点击长截图图标。在蓝框内向下滚动，预览按长图高度伸缩，达到上限后缩放展示全图。支持捕获排除的 Windows 可在面板保持可见时抓帧。滚动过快导致接缝缺失时，往回滚到和已采集内容有交集的位置，或用手动拼接 |
| 区域录屏 | 点击录屏图标开始。蓝色框在录屏期间保留，点结束按钮或 Ctrl+Alt+R 停止。完成后可保存或复制 GIF、MP4，启用无损录制时还可保存 MKV |
| 视频工具 | 设置起止时间和像素裁剪区域，导出 MP4、无损 MKV 或循环 GIF；两遍调色板导出，支持取消 |

初次框选保持原屏亮度，选区确认后外侧轻微淡化。完成或取消截屏后，设置窗口留在后台，可通过托盘图标再次打开。旧版 Windows 如果无法排除覆盖选区的预览，可拖开预览面板继续自动采集，或点击「采集下一屏」。

录屏原文件位于配置目录的 `recordings`。在「截屏」设置中选择导出画质与帧率，录屏结束时预览会采用这些默认值，导出前仍可调整。画质可选原始分辨率、1080p、720p 或 480p，帧率可选原始帧率及 12、15、24、30、60 fps。选择原始帧率时按 24 fps 录制。复制 GIF 或 MP4 会将文件放入剪贴板，可粘贴到资源管理器及支持文件粘贴的应用。小于或等于 16 MiB 的 GIF 同时提供 GIF 数据。录屏静音，正常退出会等待录屏收尾。

无损 MKV 保留奇数尺寸。录屏 MP4 用边缘填充满足编码所需的偶数宽高。MP4 使用 CRF 18，GIF 使用 256 色调色板。需要原始录制画质时可以选无损 MKV。

录屏预览的进度条两端可直接拖动裁剪，起止时间显示到毫秒。点击左／右手柄后，用左右方向键每次微调一帧，Shift＋方向键移动十帧；按原始录制帧率对齐，例如 24 fps 约为每帧 41.667 ms。中间进度条用于定位播放，重置按钮恢复整段录屏。导出 GIF 默认采用「快速调色」，也可选择适合丰富渐变的「精细调色」；两种模式均保留所选尺寸与帧率，调色精度及抖色方式有所不同。

长截图上限 4000 万像素以限制主动操作的内存。拼接支持常见固定页头和页脚，页脚只保留一次。大面积动态内容、重复画面或跨过整屏后缺少重叠时，可向上回滚以恢复自动匹配。暂未实现 OCR、自动滚轮滚动、系统音频 / 麦克风录制及录屏暂停。

## 五个效率工具

| 工具 | 功能 |
| --- | --- |
| 快速启动器 | 后台索引开始菜单，搜索应用、收纳文件和工具；安全表达式计算 |
| 剪贴板历史 | 开启后本机保存文本 / 图片，搜索、置顶、复制、清空未置顶项；尊重 Windows 监控排除标志 |
| 便签与任务 | 自动保存、搜索、完成 / 待办、归档 / 还原、到期提醒。勾选「贴到桌面」显示玻璃便签卡片，拖动标题移动，拖动边缘或角落调整大小，尺寸与位置自动保存；正文滚轮浏览且不显示滚动条。右键「便签颜色…」或编辑页「调色板」选择任意颜色，双击标题编辑 |
| 文件工作台 | 后台扫描、150 项分页、只读预览、元数据、SHA-256、批量改名预览、跨重启撤销和中断恢复 |
| 专注工作区 | 保存 / 应用壁纸及面板布局，专注 / 休息计时、可选暂停动态壁纸、会话历史和重启恢复 |

剪贴板默认关闭，单项最多 5MB，总内容约 32MiB，最多 20 项置顶，本机 SQLite 保存。敏感内容的排除取决于来源程序是否设置 Windows 标志，也可随时关闭和清空。

文件改名先预览再应用，不覆盖目标。中断后点击「恢复中断任务」；原名称被其他文件占用时停止恢复并保留文件。同一批包含多个同文件硬链接时，在移动前拒绝。工作区只调整已有分组的布局，不替换收纳内容。

## 后台与快捷键

Ctrl+Alt+A 截屏默认启用，可在「截屏」单独关闭。其他全局快捷键按需开启，包括 Ctrl+Alt+R 录屏、Ctrl+Alt+Space 启动器和 Ctrl+Alt+V 剪贴板。录屏期间会临时注册停止快捷键。若快捷键被占用，可从托盘或主界面进入截屏。

启用动态壁纸、收纳、快捷键、剪贴板、桌面便签 / 提醒或专注任务时，关闭设置会保留后台。仅设置静态壁纸且未开启后台功能时，关闭所有工具后退出，进程占用为 0。托盘可完全退出。

开机自启通过当前用户 HKCU Run 实现，登录后静默恢复已开启功能。静态壁纸交给 Windows 显示，不需常驻。

## 画质、内存与兼容性

「美化 → 鼠标与指针」提供原创流线（圆润实心）、棱镜（几何镂空）、像素（阶梯复古）三套指针，包含文本、链接、各方向调整大小、定位、人员选择和忙碌动画；手写角色依系统支持。多种 DPI 尺寸由 Windows 原生光标加载，主题选中后由轻量 C++ 辅助程序驻留等待管道指令，退出恢复 Windows 注册的方案，不写入系统指针注册表。主程序意外退出、管道断开时也会恢复；若另一个程序接管了指针，则避免覆盖它。源码运行需先执行 `tools/build_pointer_host.ps1`，发行包自带组件。

指针支持独立调色和 75%～200% 大小，按系统 DPI 加载整套角色并缩放热点。系统方案下先保存颜色和大小，选用美化指针后生效。自定义颜色在后台生成并缓存，最多保留 8 套，避免设置窗口等待。

鼠标粒子默认关闭，可与任意指针组合并单独调色。点点保留短尾迹（最多 20 点、0.42 秒）；飘落使用惯性、空气阻力和重力（最多 64 点、1.25 秒）；光芒读取当前原生指针轮廓，仅沿外缘流动（1.05 秒），跟随箭头、文本与链接等角色及当前大小，轮廓缓存最多 16 项。三种效果均最多 30 fps，停止后淡出并停止绘制定时器；关闭后释放窗口与鼠标监听。指针主题或粒子开启时关闭设置保留后台，完全退出会恢复系统方案并关闭特效。

「设置 → 系统护眼 · 夜间模式」打开 Windows 原生夜间模式页面，由系统控制开关、暖色强度和时间计划。应用不通过未公开注册表或屏幕叠色模拟系统开关。旧 Windows、不支持的显示驱动、远程会话或被系统策略禁止时入口灰色。驱动的最终可用性以 Windows 设置页为准。

导入的壁纸原样复制到 `data/wallpapers`。GIF 与视频通过独立媒体进程中的 QMediaPlayer → QVideoWidget 原生通道播放该副本。切换时等旧进程退出，收到新素材有效首帧后才显示已应用；超时只清理媒体进程。在线动态预览和视频封面也与设置线程隔离。详见[播放与切换排查](media-playback-design.zh-CN.md)。视频封面从视频帧生成，缓存到 `data/thumbnails`。铺放方式只改变显示布局，原始文件和壁纸副本都保持原画质。

Python / Qt 无法承诺几 MB 的完整桌面工具。本版采用按需导入、事件驱动、关闭工具释放窗口、单播放器、后台线程、无 WebEngine，FFmpeg 只在任务期间启动；原生玻璃不在 Python 中逐帧模糊。

后台快捷键只注册热键事件，调用时才读取屏幕和创建截图工具。FFmpeg 在录制、探测或导出任务期间启动。最新打包版数据见 [测试报告](../TEST_REPORT.md)。

此前同机不同场景的工作集参考：GIF 约 117MB，720p 视频约 244MB，三个收纳面板约 175MB。打开更多工具会增加占用；这些值不能相加，也不是性能保证。4K、高帧率、编码和显卡会影响 CPU、内存和显存。详情见 [测试报告](../TEST_REPORT.md)。

以 Windows 10 / 11 x64、普通 SDR 为目标。动态壁纸同一时刻一个文件、可选单屏；未实现每屏独立动态播放、跨屏拼接和 HDR / 色彩准确性保证。Explorer 壁纸层及可选玻璃接口受系统版本影响。收纳 / 便签支持所有者重建通知和屏幕位置修复，物理多屏拔插与真实 Explorer 重启仍需扩大验证范围。


## 源码运行与构建

需要 Windows x64 / Python 3.11。安装 requirements.txt 后运行 main.py。安装包和免安装版自带 FFmpeg 录屏组件。从源码运行时，可将支持 gdigrab、libx264、ffv1 和调色板滤镜的 ffmpeg.exe 放入 `runtime` 或加入 PATH。静态、GIF 和视频壁纸使用包内 Qt 运行库。

```powershell
python -m pip install -r requirements.txt
python main.py
python tools/run_tests.py
.\build.ps1
```

使用 python tools/run_tests.py --desktop 可运行交互桌面测试。构建脚本隔离 PATH，避免收集其他软件的同名 DLL。应用源码采用 [MIT](../LICENSE)。运行库保留各自的 [第三方许可](../THIRD_PARTY_NOTICES.md)。

## 二开与贡献

把 [轻块桌面二开 Skill](../skills/light-block-desktop-dev/SKILL.md) 交给 Agent，按需选择自行维护或向上游贡献。项目约定见 [AGENTS.md](../AGENTS.md)，合并与发布分别见 [贡献指南](../CONTRIBUTING.md) 和 [发布手册](release.md)。

外观设置统一放在「美化」，壁纸与效率工具入口缩写为「壁纸」「工具」。新配置的收纳布局默认居下，已有居上或居中选择保留。任务栏圆角始终显示，可在关闭美化时预设；开启后实时作用于三段原生背景，自动隐藏时也保留圆角设置。便签自选颜色在下拉框显示短标签与色块，完整色值在提示中显示。

在「美化 → 桌面收纳设置」可分别选择「图标背景颜色」「收纳背景颜色」，适用于居上、居中、居下及分组内的图标。分组文件夹保留各自颜色，浅色面板会自动调整标题、图标名称、返回按钮和搜索图标的对比度。「恢复默认收纳配色」同时清除这两项自选颜色，不改动分组、透明度或布局。改色只重绘，不重新读取图标或重建布局。

# 轻块桌面使用指南

[English](usage.en.md) · [项目首页](../README.md)

本地运行的 Windows 桌面工作台，Python 3.11 + PySide6。包含静态 / GIF / 视频壁纸、可选玻璃桌面收纳、截图录屏，以及五个独立效率工具。无账户、广告、遥测或云端上传。

## 直接使用

Setup 跟随 Windows 显示语言，支持简体中文、繁体中文和英文。程序启动时读取相同设置，中文系统显示简体中文，其他语言使用英文。

下载 Releases 的 `Setup-x64.exe` 安装，或完整解压 `Windows-x64.zip` 后运行 `轻块桌面.exe`。便携版保留同目录的 `_internal` 文件夹。

升级前退出旧版，再启动新版。沿用 `%LOCALAPPDATA%\StillWallpaper` 的壁纸库、分组和设置。已开启自启动的用户可在新版重新打开自启动开关以更新路径。截图快捷键 Ctrl+Alt+A 默认开启，收纳和剪贴板历史仍可分别开启。

单击设置窗口右上角的太阳或月亮图标，直接切换浅色和深色。应用会记住选择。

## 桌面收纳

进入「桌面收纳」并打开开关。收纳主页和分组网格隐藏滚动条，仍可用滚轮浏览。桌面中央显示手机式文件夹总览，Windows 原生图标同时隐藏。项目按文件夹、快捷方式、系统图标和文件后缀归类。「同步分类」可补充新项目。

单击文件夹放大为应用网格。单击空白处、点到面板外，或成功打开项目后，网格收回到文件夹总览。开启和收回时，桌面窗口尺寸保持固定，图标和文字在过渡期间保持可见。分组只读取当前视口内的图标，滚动到新项目时继续读取。动效跟随 Windows 的动画效果设置。鼠标进入时面板和文字一起变清晰，离开时一起淡化。可设置分组名称、颜色、图标尺寸及面板透明度。

点击桌面收纳面板上的标题可直接编辑。展开分组后，点击分组名也可编辑。回车或点击别处保存，Esc 取消。名称可以留空，原位置仍可再次点击。右键面板可选择「添加新分组」或使用其他管理操作。

拖入应用、文件和文件夹可添加入口。项目可重命名显示名称、排序或移至其他分组。

关闭收纳或正常退出应用会恢复 Windows 桌面图标的原显示状态和布局。此前版本移动到托管目录的文件会尝试还原到原桌面目录，Windows 为这些返回的文件安排图标位置。

## 截屏

| 工具 | 功能 |
| --- | --- |
| 选区 | 默认 Ctrl+Alt+A 打开统一截屏工具。可在「截屏」页按下一组键并点击「应用」。支持智能窗口、手动区域和当前屏幕。Alt 选整个窗口，蓝框手柄调整尺寸，右侧移动图标用于拖动选区。右键清空当前选区并重选，无选区时右键退出 |
| 标注编辑 | 选区下方是一排图标。点「文字」后在选区内直接输入。工具栏可选择字体、字号、颜色和加粗、斜体、下划线。点击空白提交，拖动文字调整位置，双击继续编辑。普通截屏中，光标放在文字或已画的箭头、直线、序号等标注上时，滚轮可调标注大小，选区尺寸保持不变 |
| 贴图 | 在选区工具栏点「贴图」直接置顶。双击关闭并复制图片到系统剪贴板。右键可隐藏或显示边框 |
| 长截图 | 点击长截图图标。在蓝框内向下滚动，预览按长图高度伸缩，达到上限后缩放展示全图。支持捕获排除的 Windows 可在面板保持可见时抓帧。滚动过快导致接缝缺失时，往回滚到和已采集内容有交集的位置，或用手动拼接 |
| 区域录屏 | 点击录屏图标开始。蓝色框在录屏期间保留，点结束按钮或 Ctrl+Alt+R 停止。完成后可保存或复制 GIF、MP4，启用无损录制时还可保存 MKV |
| 视频工具 | 设置起止时间和像素裁剪区域，导出 MP4、无损 MKV 或循环 GIF；两遍调色板导出，支持取消 |

初次框选保持原屏亮度，选区确认后外侧轻微淡化。完成或取消截屏后，设置窗口留在后台，可通过托盘图标再次打开。旧版 Windows 如果无法排除覆盖选区的预览，可拖开预览面板继续自动采集，或点击「采集下一屏」。

录屏原文件位于配置目录的 `recordings`，可以从完成窗口打开。复制 GIF 或 MP4 会将文件放入剪贴板，可粘贴到资源管理器及支持文件粘贴的应用。小于或等于 16 MiB 的 GIF 同时提供 GIF 数据。录屏静音，正常退出会等待录屏收尾。

无损 MKV 保留奇数尺寸。录屏 MP4 用边缘填充满足编码所需的偶数宽高。MP4 使用 CRF 18，GIF 使用 256 色调色板。需要原始录制画质时可以选无损 MKV。

长截图上限 4000 万像素以限制主动操作的内存。拼接支持常见固定页头和页脚，页脚只保留一次。大面积动态内容、重复画面或跨过整屏后缺少重叠时，可向上回滚以恢复自动匹配。暂未实现 OCR、自动滚轮滚动、系统音频 / 麦克风录制及录屏暂停。

## 五个效率工具

| 工具 | 功能 |
| --- | --- |
| 快速启动器 | 后台索引开始菜单，搜索应用、收纳文件和工具；安全表达式计算 |
| 剪贴板历史 | 开启后本机保存文本 / 图片，搜索、置顶、复制、清空未置顶项；尊重 Windows 监控排除标志 |
| 便签与任务 | 自动保存、搜索、完成 / 待办、归档 / 还原、到期提醒。勾选「贴到桌面」显示玻璃便签卡片，可拖动，双击编辑 |
| 文件工作台 | 后台扫描、150 项分页、只读预览、元数据、SHA-256、批量改名预览、跨重启撤销和中断恢复 |
| 专注工作区 | 保存 / 应用壁纸及面板布局，专注 / 休息计时、可选暂停动态壁纸、会话历史和重启恢复 |

剪贴板默认关闭，单项最多 5MB，总内容约 32MiB，最多 20 项置顶，本机 SQLite 保存。敏感内容的排除取决于来源程序是否设置 Windows 标志，也可随时关闭和清空。

文件改名先预览再应用，不覆盖目标。中断后点击「恢复中断任务」；原名称被其他文件占用时停止恢复并保留文件。同一批包含多个同文件硬链接时，在移动前拒绝。工作区只调整已有分组的布局，不替换收纳内容。

## 后台与快捷键

Ctrl+Alt+A 截屏默认启用，可在「截屏」单独关闭。其他全局快捷键按需开启，包括 Ctrl+Alt+R 录屏、Ctrl+Alt+Space 启动器和 Ctrl+Alt+V 剪贴板。录屏期间会临时注册停止快捷键。若快捷键被占用，可从托盘或主界面进入截屏。

启用动态壁纸、收纳、快捷键、剪贴板、桌面便签 / 提醒或专注任务时，关闭设置会保留后台。仅设置静态壁纸且未开启后台功能时，关闭所有工具后退出，进程占用为 0。托盘可完全退出。

开机自启通过当前用户 HKCU Run 实现，登录后静默恢复已开启功能。静态壁纸交给 Windows 显示，不需常驻。

## 画质、内存与兼容性

GIF 与视频均通过 QMediaPlayer → QVideoWidget 原生通道，直接读取原文件，无播放前压缩、转码或 Python 逐帧解码。缩略图仅用于界面；填充 / 完整显示 / 拉伸决定显示布局，不改写素材。

Python / Qt 无法承诺几 MB 的完整桌面工具。本版采用按需导入、事件驱动、关闭工具释放窗口、单播放器、后台线程、无 WebEngine，FFmpeg 只在任务期间启动；原生玻璃不在 Python 中逐帧模糊。

后台快捷键只注册热键事件，调用时才读取屏幕和创建截图工具。FFmpeg 在录制、探测或导出任务期间启动。最新打包版数据见 [测试报告](../TEST_REPORT.md)。

此前同机不同场景的工作集参考：GIF 约 117MB，720p 视频约 244MB，三个收纳面板约 175MB。打开更多工具会增加占用；这些值不能相加，也不是性能保证。4K、高帧率、编码和显卡会影响 CPU、内存和显存。详情见 [测试报告](../TEST_REPORT.md)。

以 Windows 10 / 11 x64、普通 SDR 为目标。动态壁纸同一时刻一个文件、可选单屏；未实现每屏独立动态播放、跨屏拼接和 HDR / 色彩准确性保证。Explorer 壁纸层及可选玻璃接口受系统版本影响。收纳 / 便签支持所有者重建通知和屏幕位置修复，物理多屏拔插与真实 Explorer 重启仍需扩大验证范围。


## 源码运行与构建

需要 Windows x64 / Python 3.11。安装 requirements.txt 后运行 main.py。录屏 / 导出需要另外安装支持 gdigrab、libx264、ffv1 和调色板滤镜的 FFmpeg CLI。应用会从 PATH 或本地构建的 runtime/ffmpeg.exe 查找。静态、GIF 和视频壁纸可直接使用包内 Qt 运行库。

```powershell
python -m pip install -r requirements.txt
python main.py
python tools/run_tests.py
.\build.ps1
```

使用 python tools/run_tests.py --desktop 可运行交互桌面测试。构建脚本隔离 PATH，避免收集其他软件的同名 DLL。应用源码采用 [MIT](../LICENSE)。运行库保留各自的 [第三方许可](../THIRD_PARTY_NOTICES.md)。

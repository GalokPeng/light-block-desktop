# 官网虚拟桌面与 v2.0.6 对照设计

基准是正式标签 [v2.0.6](https://github.com/GalokPeng/light-block-desktop/tree/v2.0.6)。复刻对象包括可见布局、动作顺序、控件参数、操作结果以及取消后的状态。网站的电脑边框、下载按钮和顶部提示属于官网。电脑屏幕以内使用安装版的产品名称、图标与词汇。

## 设计与实施顺序

1. 共用原版图标、壁纸、指针位图与热点。六个工作空间使用同一个窗口模型。桌面快捷方式和任务栏打开同一实例。手机单指操作等价于点击，桌面快捷方式保留双击和键盘打开。
2. 将“选中条目”“正在预览”“已下载”“已应用”独立保存。切换页面时结束媒体解码，异步结果只交给发起它的界面。在线媒体保留来源和许可。
3. 用原版工具顺序、图标和选区边缘定位构建两行工具栏。冻结底图、选区、标注对象及历史分开保存。复制、保存和贴图基于同一次合成。擦除仅影响标注层。
4. 分别核对收纳、任务栏、长图、录屏及工具的细节。每项记录输入、状态变化和可观察结果。操作系统效果在虚拟桌面内呈现，不能提供的设置清楚注明。
5. 桌面与窄屏分别走中英文路径。用合成场景对照安装版图片和源码，验证命中、输入、边缘、取消、网络失败、资源释放和下载区跳转。覆盖程度按实际通过的动作记录。

## 本次网页实现与复核

- **窗口和桌面**。初始可见轻块桌面设置窗和带快捷箭头的应用图标。最小化、关闭、双击图标、Enter、任务栏、最大化与底边唤出均作用于屏内窗口。主题和语言在设置窗切换。为让访客一进入屏幕就能看出指针效果，体验桌面初始选择流线方案。
- **壁纸**。六个内置素材沿用正式版名称与顺序。点卡片只更新预览，应用需要单独点击。静图显示原图，GIF 自动动，视频按需播放。在线图库与正式目录对应，共 52 张静图、20 个 GIF 和 33 个视频。官网提供 105 张封面，并为 53 个动态素材提供最长五秒的无声循环预览。原文件按目录中的字节数与 SHA-1 验证后进入本地图库。原站失败时会显示重试说明，可另选预览画质体验桌面。
- **指针**。从三套原始 CUR / ANI 导出 17 种角色、热点与忙碌动画。桌面、文本、链接、选区边缘与拖动手柄会切换角色。指针与粒子独立配色，系统、流线、棱镜、像素四个按钮沿用正式版的两列布局。
- **截屏**。选择后出现七组标注工具和靠近选区的侧栏，工具参数在第二行。保留撤销、重做、文字续编、局部擦除、画笔及框选马赛克。贴图可以多张并存，保留标注以便继续编辑。长图有实帧重叠比对、滚动采集、下一屏及完成贴图。虚拟文件夹内的图册可用作长截图滚动对象。
- **录屏**。从虚拟桌面实际采集选定区域，录制最长 12 秒。录制后可以回放、拖双端时间轴、键盘微调、裁剪画面和涂鸦。网页通过浏览器提供的视频编码器和内置 GIF 编码导出。原生程序的系统声音、麦克风、无损 MKV、硬件采集和完整分辨率长录制需在 Windows 中体验。
- **美化与工具**。桌面内容有独立的背景与底板透明度、上中下布局、分组、搜索、按名称或时间排序、临时图标、手动及延时收纳。模拟文件具备打开、重命名、删除和属性菜单。工具包括快速启动与四则运算、剪贴板、便签与任务、虚拟文件 SHA-256 和可撤销批量改名、专注计时与布局恢复。
- **运行范围**。网页只控制显示器框内的桌面。系统重启、Explorer 注入、Windows 登录启动、全系统快捷键、目录恢复、后台提醒和安装包更新仍依赖桌面程序。移动设备使用触摸交互，窗口和工具栏针对屏宽换行。文字栅格化、系统控件以及不同浏览器实际支持的编解码器会有差异。

### 验证与再生成

在仓库根目录运行 `python -m http.server 49173 --directory site/public`，再用装有 Playwright、Pillow 和 Chrome 的 Python 运行 `python tests/web_desktop_parity.py`。测试检查导出 PNG 的尺寸和像素、裁剪后的 GIF、滚动拼接、贴图编辑、桌面工具、移动端和中英文下载入口。实际目录测试会加载每个封面和动态片段元数据，受控素材则用于验证原件下载的完整性。

`tools/web_demo_art.py` 从安装版素材重新生成指针和标注图形。`tools/web_demo_previews.py --cache <已核验原件目录> --fetch` 从正式目录生成网页清单、封面和预览，使用 FFmpeg 和 Pillow。每项预览沿用源作品许可，作者、来源、许可链接与原件地址随预览显示。原始大文件保留在各授权来源。Vercel 构建时运行 `node tools/build_desktop_demo.mjs`，把图库索引和光标图集嵌入虚拟桌面的 HTML。弱网进入体验时即可取得指针数据与列表，封面和视频仍按需加载。

更细的原版参考见[截图行为矩阵](cpp-migration/CAPTURE_PARITY_MATRIX.md)和[录屏行为矩阵](cpp-migration/RECORDING_PARITY_MATRIX.md)。表中的验收路径是目标，用于逐项追踪实现进展。

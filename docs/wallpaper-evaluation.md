## 如何比较热度

1. 先检查明确的公开分发许可、作者、实际来源文件尺寸、字节数和摘要。宽度低于 1920、高度低于 1080 或超过 20,000,000 字节直接排除，不通过软件处理凑数量。
2. 再看画面是否适合作为桌面：清晰、有完整构图；排除编辑遮罩、胶片片头和不适合常驻桌面的内容。GIF 允许自然、天文、几何示意及趣味题材。相近机位的同一海岸拍摄不重复占名额。
3. 静图在通过观感和大小筛选的年度决选候选中按支持票降序选择。Archive 视频在自己的候选池按收藏数、浏览量排序；Commons 视频在自己的候选池按评选支持票、近 30 天文件页浏览排序，再合并为 20 段。不同口径分池处理，不把收藏与评选票混成一个分数。
4. 没有公开的点赞、收藏或浏览指标记为 `null`。Commons 的支持票是评选投票，不是社交点赞；Archive 的条目 `downloads` 搜索字段在作品页标为 Views，本项目展示为来源浏览量。
5. 不把不同站点、不同统计时期的数值混成“全网综合热度”，不声称是全网绝对前 20。统计日期、口径、证据 URL 均随作品保留；后续数字可能变化。

## 文件与更新边界

- 目录为 schema 4，旧 schema 1/2/3 缓存或远程响应不能覆盖当前精选，因此旧 300 项和上一轮大视频都不会因刷新重新出现。新目录禁止内容分类字段，强制原生 1080p、20 MB 上限、每种媒体最多 20 项。静图／视频要求正向支持证据；GIF 不设热度门槛，但必须记录经过验证的 16:9、多帧、循环与时长。
- 来源文件直接从原站取得，沿用发布者的 JPEG、GIF、WMV、WebM、OGV 文件。正式下载流式校验长度、SHA-1 和媒体签名，保存原字节；不自行压缩，不把封面或较小预览当作来源文件。
- 当前所有视频都在 20 MB 内，按需取得同一来源文件用于预览，正式下载可重新校验后复用缓存。播放器支持 WMV 与 OGV，无需额外安装软件。动态预览总磁盘缓存上限 128 MiB，同一时刻只播放一项。
- 软件的 MIT 许可与素材许可各自适用。友链不能替代署名；详情和 `origin.json` 保留作者、作品页、许可及热度核对记录。完整列表见[逐项记录](wallpaper-sources.md)。
- 元数据和作者的许可声明可追溯，但不构成对上传作品权属的法律担保。发现版权或来源争议时，先停用对应条目再核对。

# 在线壁纸：精选直链目录与维护

在线图库从 v0.9.0 起随软件提供。当前目录为静态 20 张、GIF 10 款、视频 20 段。

## 当前行为

- 壁纸页切换「本地壁纸 / 在线壁纸」。在线页只显示静态、GIF、视频三个入口，默认静态；静态与视频各精选 20 项，GIF 保留 10 项，取消内容分类。中英文名称、原始文件名和标签在当前媒体类型内搜索。
- 所有入选来源文件宽度至少 1920、高度至少 1080，单项不超过 20,000,000 字节，须有明确的分发许可。静图／视频须有可核验正向支持证据。按用户追加的“什么类型都行”，GIF 不设热度门槛；维护者最终确认保留本地复看版的 10 项 GIF；仍要求实际验证原文件为 1080p、16:9、多帧、无限循环，保留原字节和原帧时间。
- 详情展示作者、许可和核对时的支持票或收藏、浏览数，并提供「热度依据」链接。未公开的指标为 null，不推算；不同来源与统计时期不混算。
- 列表仅绘制可见卡片，按需取得封面。GIF 封面只保存首个完整帧；点击才启动一个动态预览，停止或离开页面后释放播放器。
- 当前所有视频在 20 MB 内，预览按需取得同一来源文件，正式下载可分块重新校验后复用缓存。播放器支持 WMV 与 OGV。若未来录入独立较小预览，必须单独记录 URL、摘要和缓存路径，不能替代来源文件，同样受 20 MB 限制。
- 原文件最多两个并行流式下载，验证长度、记录的摘要算法和媒体签名后原子移入本地图库，显示「已下载」并允许应用；不重新压缩。可取消、失败重试，关闭设置后正式下载继续，退出软件则取消。
- 文件保存在当前数据目录的 wallpapers，旁边的 origin.json 和图库记录保留作者、来源、许可与热度依据。删除本地下载后可重新下载，更新素材 revision 后可下载新版。
- 遇到 HTTP 429 按 Retry-After 暂停来源请求，不绕过限流；已缓存或已下载的媒体仍可使用。

## 来源与筛选

目录 assets/online-wallpapers.json 为 schema 4，catalog_revision 为 1，仅保存 50 项 URL 和元数据；不把媒体文件存入 Git。来源包括 Wikimedia Commons 的年度图片决选、社区评选视频和公开授权 GIF（含 NASA 科学影像），以及原作者 Jeffrey Beach 在 Internet Archive 提供的 CC BY 3.0 高清 WMV。

静图按通过像素、体积与观感筛选的决选支持票排序；视频在各来源候选池内按收藏或支持票排序后合并。旧 300 项全部移除，与新条目 ID 无交集；上一轮超过 20 MB 的大视频也全部退下。旧分类和为数量自动补齐的采集脚本已移除。

检索语言、来源核对、比较口径、候选范围和排除理由见[评估记录](wallpaper-evaluation.md)。逐项作者、许可、热度证据见[来源记录](wallpaper-sources.md)。

## 目录刷新与边界

只从项目官方 GitHub HTTPS 地址获取目录。使用随包精选作为离线基线；素材预览与下载直接请求原站。目录 JSON 可独立更新。

缓存和远程目录的 (schema_version, catalog_revision) 低于随包目录时拒绝替换，防止旧 300 项或旧大文件恢复。新 schema 强制每种类型最多 20 项、原生 1080p、20 MB；静图／视频要求正向支持证据，GIF 要求 16:9、实际多帧和循环记录。GIF 未公开的热度为 null；浏览量只合计官方 API 已公开日期，并记录可用天数。获取、解析或校验失败时保留当前有效目录。原站删改文件导致摘要变化时停止下载，重新核对并递增 revision 后再接受。

素材允许来源为 Wikimedia 媒体域名与 archive.org；Archive CDN 只允许 ia 加数字构成的 archive.org / us.archive.org，以及实际下载中核对到的 dn 加数字构成的 ca.archive.org / us.archive.org 主机。拒绝 HTTP、主机伪装、未经审核的重定向和危险本地路径。

封面磁盘缓存上限 64 MiB、内存最多 32 张缩略图；动态预览磁盘缓存上限 128 MiB。离线可以使用已经下载的原文件，未缓存媒体仍依赖来源网络。

## 维护流程

1. 先核对许可是否允许本应用分发、原作者、原始像素及媒体类型；不要把“免费个人使用”当成可再分发许可。
2. 查作品级公开支持、收藏、点赞与浏览指标。保留真实字段、统计期间、核对日期及证据 URL；缺失为 null。检查画面后再在同一来源和口径内排序，不自动凑数。
3. 修改目录：稳定 ID、双语短标题、原文件 URL、文件大小、源站摘要、作者、许可和 popularity。GIF 需实际取得原文件核对像素、变化帧、循环，填写 frame_count、looped 和 duration_seconds，不能凭标题推断。需要较小预览时单独填 preview，不改动下载原文件。
4. 执行 `python tools/check_wallpaper_catalog.py`，默认核对静图 20、视频 20、GIF 不超过 20、重复文件、字段及来源。`--verify-downloads --limit 2` 可做有限真实原文件抽查；不要例行反复下载全部媒体。
5. 执行 `python tools/build_wallpaper_catalog.py --credits-only` 同步逐项署名；新增来源同步中英文 README 友链和第三方声明。
6. 执行 `python tools/run_tests.py`。在独立配置中检查三类入口、GIF 搜索与连续变化帧、真实预览、原文件下载、旧目录不能恢复，以及中英文和明暗布局。网络／界面集成测试在独立 QApplication 子进程中运行。
